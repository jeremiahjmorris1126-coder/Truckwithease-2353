## For Runnable Deployment

1. **Extract the tar.gz file**
   ```bash
   tar -xzf TRUCKWITHEASE_COMPLETE_EXPORT.tar.gz
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables** (if needed)
   - VITE_API_BASE_URL (for API calls)
   - VITE_GOOGLE_MAPS_KEY (for Maps integration)

4. **Build for production**
   ```bash
   npm run build:prod
   ```

5. **Output directory**
   - All production files go to `dist/`
   - Ready to serve from any web server
