**Issue #3: DISPATCH & ROUTING AGENT — No Real Route Calculation**

**Location:** `DispatchRoutingAgentPage.jsx:537L`

**Current State:**
- Shows 3 mock loads with calculated profit
- Displays UI for assigning loads to drivers
- No actual route optimization
- No integration with Load Board data
- No driver matching algorithm

**Missing:**
- Google Maps API integration (real route distance/time)
- HOS compliance checks (federal + state rules)
- Dead-mile elimination algorithm
- Fuel cost calculation per route
- Real driver availability check

**What Needs to Happen:**
```jsx
// When user clicks "Assign Load"
async function assignLoad(loadId, driverId) {
  setLoading(true);
  try {
    // 1. Fetch load from load board
    const load = await pb.collection("loads").getOne(loadId);
    
    // 2. Fetch driver availability
    const driver = await pb.collection("drivers").getOne(driverId);
    
    // 3. Call Google Maps to get real route
    const route = await fetch(
      `https://maps.googleapis.com/maps/api/directions/json?origin=${load.origin}&destination=${load.destination}&key=${GOOGLE_API_KEY}`
    ).then(r => r.json());
    
    // 4. Validate HOS compliance
    const hosCheck = validateHOS({
      currentHours: driver.hoursWorked,
      routeMiles: route.routes[0].legs[0].distance.value / 1609,
      state: load.pickupState,
    });
    
    if (!hosCheck.valid) {
      setError(hosCheck.reason);
      return;
    }
    
    // 5. Calculate actual profit
    const fuelCost = (route.routes[0].legs[0].distance.value / 1609) * driver.fuelCostPerMile;
    const profit = parseInt(load.rate) - fuelCost - (driver.costPerMile * distance);
    
    // 6. Assign to driver
    await pb.collection("assignments").create({
      loadId, driverId, routeDetails: route, profit, assignedAt: new Date()
    });
  } catch (e) {
    setError(e.message);
  } finally {
    setLoading(false);
  }
}
```

**Priority:** CRITICAL — Core operational feature
**Effort:** 10-12 hours (includes API setup)
**Impact:** Very High

useEffect(() => {
  async function fetchLoads() {
